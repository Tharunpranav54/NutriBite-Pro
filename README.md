# 🍽️ NutriBite Pro
NutriBite Pro is a web-based food ordering application developed as a college project. The main goal of this project is to help users order food while also promoting healthy eating habits through BMI-based meal suggestions and basic health analysis.

## Features
- User Login and Registration
- Food Menu and Ordering
- BMI Calculator
- Healthy Food Recommendations
- Shopping Cart
- Order Tracking
- AI Chat Assistant
- Dark and Light Mode
- Responsive User Interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- MySQL

## How to Run
1. Download or clone this repository.
2. Copy the project folder into the **htdocs** folder of XAMPP.
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Import the database into phpMyAdmin.
5. Open your browser and run:
   ```
   http://localhost/NutriBite-Pro/
   ```

This project was created to improve my web development skills and to build a practical application that combines food ordering with simple health-related features.
